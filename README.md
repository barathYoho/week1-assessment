# Week 1 Python Analysis Assessment

## Project Overview
Employee data analysis using Python, Pandas, NumPy and Matplotlib.

## Project Structure
- data/ - Employee dataset
- notebooks/ - Jupyter analysis notebook
- reports/ - Analysis reports and charts
- src/ - Python source code
- requirements.txt - Project dependencies

## Requirements
- Python 3.13
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook
- nbconvert

## How to Run

1. Clone the repository:
   `git clone https://github.com/barathYoho/week1-assessment.git`

2. Enter the project folder:
   `cd week1-assessment`

3. Create a virtual environment:
   `python -m venv env`

4. Activate it:
   `env\Scripts\activate`

5. Install dependencies:
   `pip install -r requirements.txt`

6. Start Jupyter:
   `jupyter notebook`

7. Open `notebooks/employee_analysis.ipynb` and run all cells.

## Key Findings

1. The dataset contains 8 employee records.
2. Average employee salary is ₹58,500.
3. IT has the highest employee count, with 3 employees.
4. Chennai has the most employees, with 4 employees.
5. Karthik has the highest salary at ₹90,000.
